# 기술사 암기카드 PWA — 시험 전 안정 버전

소방기술사 암기 이미지를 빠르게 찾고 반복해서 보는 모바일 중심 PWA입니다.

## 지금 사용할 기능
- 암기 이미지 13장 내장
- 제목/태그/키워드 검색
- 카테고리 필터
- ★ 즐겨찾기
- 🔴 모름 / 🟡 애매 / 🟢 암기완료
- ⚡ 시험직전 복습: 완료되지 않은 카드 중 랜덤 1장
- 🎲 현재 필터 범위 랜덤 카드
- 큰 이미지 뷰어 + 이전/다음
- 진도 JSON 백업/복원
- Service Worker 오프라인 캐시
- 설치형 PWA
- GitHub Pages 자동 배포용 GitHub Actions 포함

## 시험 전 운영 원칙
현재 버전은 기능 추가보다 안정성과 빠른 복습에 초점을 둡니다. 새 기능은 시험 후 개선합니다.

## 시험 후 개선 예정
1. PWA 안에서 이미지/제목/태그를 입력해 새 카드 추가
2. IndexedDB 저장 및 WebP 자동 변환
3. Google Drive 자동 백업/복원
4. GitHub 인증 후 공식 배포본 일괄 동기화
5. 간격 반복 복습
6. 기존 기술사 STUDY PWA와 주제/기출/우수답안 연결
