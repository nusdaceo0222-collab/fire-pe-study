● 준비 중 즐겨찾기와 암기상태는 이 기기에 저장됩니다. 시험 전에는 가끔 JSON 백업을 권장합니다.
📌 시험 전, 이렇게 쓰면 됩니다
  1. 처음 볼 때: 카드 이미지를 크게 보고 상태를 🔴 모름 / 🟡 애매 / 🟢 암기완료로 표시합니다.
  2. 반복할 때: 복습필요 또는 ⚡ 시험직전 복습만 사용합니다.
  3. 중요한 것: ★ 즐겨찾기에 넣고 시험장 가기 전에는 즐겨찾기만 빠르게 봅니다.
  4. 검색: RTI, 알퍼트, 피난, 온도처럼 기억나는 단어만 입력해도 찾을 수 있습니다.
  5. 데이터 안전: 진도는 기기에 저장되므로 중요한 시점에는 진도 백업으로 JSON 파일을 보관합니다.
🛠 시험 후 개선 참고사항
  • PWA 안에서 + 암기카드 추가: 이미지 선택 → 제목/카테고리/태그 입력 → 즉시 카드 생성
  • 카드와 이미지를 IndexedDB에 저장하고, 새 이미지는 자동 WebP 변환
  • Google Drive에 카드·진도·설정 자동 백업/복원
  • GitHub 인증 후 원할 때 공식 배포본으로 일괄 동기화
  • 모름/애매 카드의 복습주기를 자동 계산하는 간격 반복 기능
  • 기존 기술사 STUDY PWA의 주제·기출·우수답안과 암기카드 상호 링크

현재 버전 원칙: 시험 전에는 기능을 늘리지 않고, 검색·복습·즐겨찾기·진도표시·오프라인 사용에 집중합니다.
